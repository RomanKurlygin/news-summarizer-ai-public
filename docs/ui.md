# Пользовательский интерфейс

Streamlit обращается к FastAPI через серверный HTTP-клиент. Сначала зарегистрируйте собственный аккаунт и войдите. JWT хранится в Session State, выход и истечение токена очищают сеанс. Ключи внешних провайдеров остаются в backend.

- **Суммаризация.** Введите собственную новость, выберите установленную модель, baseline или full, язык и число предложений. В baseline используется генерация без RAG и дополнительного цикла проверки. Для full нужен отдельно подготовленный индекс и данные.
- **Работа агентов.** Показывает фактически выполненные шаги, замечания, оценки и правки. Можно открыть журнал своих запросов.
- **Сравнение моделей и режимов.** Читает собственные оценки и настроенный архив агрегатов. Публичный репозиторий не содержит готовых результатов и тестовых новостей.
- **История запросов.** Показывает собственные обработки с фильтрами. Права на детали проверяет API.
- **Ручная проверка.** Доступна editor и admin. Решение сохраняется отдельно от автоматического вердикта. Включение исправленной пары в корпус требует проверки holdout.
- **База знаний и справочник.** Доступны admin для CRUD и импорта CSV. Учебный корпус и справочник поставляются пользователем.
- **Состояние сервисов.** Показывает доступность подключённых компонентов. Статистика кэша доступна администратору.

Для языка резюме auto определяет русский или английский по исходнику. ru и en явно задают язык ответа. Фильтр поиска RAG задаётся отдельно. При несовпадении языка допускается один журналируемый повтор на той же модели. Число предложений и фактический язык показаны под результатом.

verified означает прохождение автоматических проверок. needs_review требует сверки человеком. Небольшая LLM может ошибаться в фактах и грамматике при высоком балле Critic.

Запуск и настройка роли описаны в [README](../README.md). Для контейнерного запуска используйте [инструкцию развёртывания](deployment.md).
